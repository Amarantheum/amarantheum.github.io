The basic layout of the computer
  
![image](/assets/images/minecraft-computer/ram.png)
**The RAM module:** This module stores 256 bytes of random access memory using inline architecture

![image](/assets/images/minecraft-computer/bdc.png)
**The binary to decimal converter module:** This module takes a binary encoded number and converts it to binary coded decimal using the double dabble method

![image](/assets/images/minecraft-computer/passwordinput.png)
**The password input module:** This module stores a password input as 16 bits of binary coded decimal
